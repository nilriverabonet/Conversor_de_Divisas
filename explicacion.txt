1. ESTRUCTURA DEL PROYECTO (MODULARIDAD)
--------------------------------------------------------------------
Para mantener el código lo más simple posible y a la vez cumplir con
el criterio de "Calidad del código: modularidad y claridad" de la
rúbrica, el proyecto se ha dividido en dos archivos principales:

- logica.py:
  Contiene toda la lógica de negocio: la petición HTTP a la API del
  Banco Central Europeo (BCE), el parseo del XML y la fórmula
  matemática de conversión. No sabe nada de ventanas ni botones.

- main.py:
  Contiene únicamente la interfaz gráfica (GUI) hecha con Tkinter.
  Llama a las funciones de logica.py para obtener los datos y hacer
  los cálculos, y se encarga de mostrar todo al usuario y validar
  lo que escribe.

- requirements.txt:
  Lista la única librería externa necesaria: requests.
  (Tkinter y xml.etree.ElementTree ya vienen instalados con Python).


2. EXPLICACIÓN PASO A PASO (SEGÚN LA RÚBRICA)
--------------------------------------------------------------------

A) API - Petición HTTP GET (logica.py -> descargar_xml)
   - Se utiliza la librería `requests` para hacer una petición GET a:
     https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml
   - Se añade `timeout=10` para evitar que la app se quede colgada
     si no hay conexión.
   - Se comprueba que `respuesta.status_code == 200` (petición
     correcta). Si no es 200, se lanza una excepción `ConnectionError`.
   - Devuelve `respuesta.content` (los bytes del archivo XML).

B) PARSING XML (logica.py -> parsear_xml)
   - Se usa la librería estándar `xml.etree.ElementTree` (importada
     como `ET`).
   - `ET.fromstring(contenido_xml)` convierte el texto/bytes XML en
     un árbol de nodos que Python puede recorrer.
   - Creamos el diccionario `tasas = {"EUR": 1.0}` desde el inicio.
     Esto es obligatorio porque el XML del BCE da todas las tasas
     respecto al Euro (1 EUR = X moneda), así que el propio EUR no
     viene en el XML y hay que añadirlo manualmente con valor 1.0.
   - Con `for elemento in raiz.iter():` recorremos todos los nodos
     del árbol XML sin complicarnos con los namespaces del XML:
       * Si el nodo tiene el atributo `"time"`, guardamos la fecha.
       * Si el nodo tiene `"currency"` y `"rate"`, guardamos la
         moneda y su tasa convertida a número decimal (`float`).
   - La función devuelve `(fecha, tasas)`.

C) COMPRENSIÓN MATEMÁTICA - CONVERSIÓN CRUZADA (logica.py -> convertir_divisa)
   - Como todas las tasas están en base Euro, para pasar de cualquier
     Moneda Origen a cualquier Moneda Destino (por ejemplo, de USD a
     JPY) usamos el Euro como puente:

       1. Pasamos el importe a Euros:
          importe_en_euros = importe / tasas[moneda_origen]

       2. Pasamos de Euros a la moneda destino:
          cantidad_final = importe_en_euros * tasas[moneda_destino]

   - Fórmula completa:
       CantidadFinal = (Importe / TasaOrigen) * TasaDestino

   - Esta misma fórmula funciona también cuando el origen o el
     destino es EUR, porque su tasa es 1.0.

D) INTERFAZ GRÁFICA Y VALIDACIÓN (main.py -> ConversorApp)
   - Se ha usado Tkinter (`tkinter` y `ttk.Combobox`) porque viene
     integrado en Python, es muy ligero y permite ejecutar la app
     directamente con `python main.py`.
   - Carga automática: En `__init__`, nada más abrir la aplicación,
     se llama a `obtener_datos_bce()`. Si falla Internet o el
     servidor del BCE, muestra un aviso con `messagebox.showerror`
     y cierra la ventana limpiamente.
   - Componentes de la ventana:
       * Etiqueta con el título y etiqueta visible con la fecha de
         actualización extraída del XML.
       * Campo de texto (`tk.Entry`) para introducir la cantidad.
       * Desplegable (`ttk.Combobox`, solo lectura) para Moneda Origen.
       * Desplegable (`ttk.Combobox`, solo lectura) para Moneda Destino.
       * Botón "Calcular Conversión" que ejecuta el método `calcular()`.
       * Etiqueta de resultado que muestra el cálculo con 2 decimales.
   - Validación de errores (método `calcular()`):
       * Sustituye comas por puntos (`.replace(",", ".")`) por si el
         usuario escribe decimales con coma (ej: 10,50).
       * Usa un bloque `try ... except ValueError:` al convertir el
         texto a `float`. Si el usuario escribe letras o lo deja
         vacío, muestra un mensaje de error en rojo sin que el
         programa se cierre.
       * También comprueba que la cantidad no sea negativa.

4. RESUMEN RÁPIDO PARA LA DEFENSA ORAL (10 MINUTOS)
--------------------------------------------------------------------
- ¿Por qué 2 archivos?
  Para separar la lógica de datos/cálculo (logica.py) de la interfaz
  gráfica (main.py). Así el código es más limpio, modular y fácil
  de mantener.

- ¿Por qué añades EUR: 1.0 manualmente?
  Porque el BCE toma el Euro como referencia (1 EUR = X moneda), así
  que el Euro no aparece en el XML. Sin añadirlo, no podríamos
  convertir desde o hacia Euros.

- ¿Cómo conviertes de USD a JPY si no tienes la tasa directa?
  Usando el Euro como moneda puente: divido el importe entre la tasa
  de USD (obtengo Euros) y multiplico el resultado por la tasa de JPY.

- ¿Qué pasa si el usuario escribe letras en la cantidad?
  Al hacer `float(texto)` dentro de un `try`, salta un `ValueError`,
  lo capturamos en el `except` y mostramos un mensaje de error en la
  interfaz sin que la aplicación falle.
